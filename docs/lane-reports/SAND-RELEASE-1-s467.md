## 6. Fix (s467 free-lane, DeepSeek v4-pro) — 4 reds + the dev-server export error

Two root causes, both fixed in the working tree (no commit, no push, no deploy):

1. **`output: "export"` broke every dev API route.** With export mode set globally in `next.config.ts`, `next dev` returns 500 for every route handler under `src/app/api` (Next requires `force-static` on each one). The e2e battery runs against `next dev`, so `/api/platforms`, `/api/snapshot` and `/api/ollama/tags` all 500'd — that alone broke the platform-database API test and the dev log carried `export const dynamic = "force-static"/revalidate not configured ... with "output: "export"`.
   - Fix: `next.config.ts` now sets `output: "export"` only when `SAND_STATIC_EXPORT=1`, and `scripts/build-static.mjs` sets that flag for the export build. `next dev` keeps the default output, so the dev-only API routes serve again and the error is gone. The release build still moves `src/app/api` aside and ships zero `/api/*` in `out/`.
2. **An infinite React render loop on the play screen.** `useEffect(() => { updateMore(); })` (no dependency array) in `src/components/terminal/TerminalPlay.tsx` recomputed the "-- MORE --" pager cue after every render and set state, raising `Maximum update depth exceeded` in React dev. The Next dev overlay then intercepted every click, which is what killed the editor-play and save/resume paths.
   - Fix: the effect now runs on `[updateMore, sidebarTab, selectedUnitId, ordersOpen]`.
